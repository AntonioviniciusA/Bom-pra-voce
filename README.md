# Bom pra Você

Site público, painel local Electron e backend Supabase.

- [Documentação organizada](docs/README.md)
- [Operação da vitrine e publicação de produtos](docs/vitrine-painel.md)
- [Biblioteca única de imagens](bom-pra-voce-novo/src/images/README.md)

Site: `npm start --prefix bom-pra-voce-novo`. Para abrir o painel, execute `npm start` na pasta `painel-local`.
Cada aplicação utiliza sua configuração local do Supabase; nunca coloque credenciais administrativas no site.
